Widget Export-import

Cet exemple montre comment configurer le code HTML et JavaScript pour obtenir un rendu conforme au DSFR.

C'est un exemple minimal. Il n'y a aucun traitement avant l'import. Si vous exportez puis importez, vous constaterez que les lignes sont doublonnées. Les références sont cependant indépendantes et les images copiées.

Importer

Le bouton "Exporter les données" s'utilise depuis le document à mettre à jour. Il doit avoir l'attribut id="export".

Importer

Le bouton "Importer les données" s'utilise depuis un document vierge (vous venez juste d'instancer le nouveau modèle). Il doit avoir l'attribut id="import".
